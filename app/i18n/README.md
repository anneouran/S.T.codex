# 日本語・繁體中文（台湾）

- メニュー上部で選択。初期値は日本語。設定はブラウザの `st-codex-language` に保存する。
- `zh-TW.json` は日本語原文をキーにした台湾向け繁体字訳。日本語の原稿を編集せず、表示時に本文・名前・場所・選択肢を訳す。改行ごとの進行単位や演出指定は翻訳しない。
- プロローグとEp.1〜5、紹介文、操作・読み上げ用ラベルを対象とする。画像内の日本語は今回の対象外。
